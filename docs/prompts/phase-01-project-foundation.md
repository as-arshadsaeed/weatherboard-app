# Phase 1 — Project Foundation

## Objective

Establish the initial WeatherBoard application foundation.

## Instructions for Claude Code

Build a responsive, single-page weather application called WeatherBoard.

### Technology

- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- Lucide icons

### Requirements

1. Create a clean and maintainable project structure.
2. Build the main weather dashboard layout.
3. Implement responsive layouts for mobile, tablet, and desktop.
4. Create reusable UI components.
5. Include loading, empty, and error presentation states.
6. Establish consistent typography, spacing, and visual styling.
7. Ensure accessible semantic HTML and keyboard navigation.
8. Add basic unit and end-to-end testing infrastructure.

### Responsive requirements

Test at:

- 375px mobile
- 768px tablet
- 1280px desktop

### Documentation

- Create README.md.
- Document installation and development commands.
- Document the project architecture.

### Git requirements

- Create branch: feature/project-foundation
- Use Conventional Commits.
- Do not push directly to main.
- Do not merge without approval.

### Validation

Run:

- TypeScript checks
- ESLint
- Unit tests
- End-to-end tests
- Production build

Do not consider the phase complete until all required checks pass.
